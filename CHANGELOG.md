# Changelog

All notable changes to this project will be documented in this file.

---

## [1.0.0]

### Added
- Markdown editor with real-time preview
- Drag & drop of `.md` / `.markdown` / `.txt` files
- Scroll sync between editor and preview (toggle)
- Resizable editor/preview panels
- Export to PDF through the browser print dialog
- Copy of the generated HTML to the clipboard
- Syntax highlighting of fenced code blocks (highlight.js)
- GitHub Flavored Markdown support (marked.js v9)
